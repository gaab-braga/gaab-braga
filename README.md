# Gabriel Braga

Analista de dados em FP&A, em Brasília. Trabalho com Python, SQL e Power BI, e gosto de transformar planilha em pipeline que dá para testar.

### Projetos

- **[AML-Ops-Engine](https://github.com/gaab-braga/AML-Ops-Engine)**: detecção de lavagem de dinheiro em 5 milhões de transações (base pública IBM HI-Small). XGBoost com validação temporal 80/20: ROC-AUC de 0,956 e PR-AUC de 0,22 no teste. Tem API em FastAPI e Docker.
- **[mds-agent-partner](https://github.com/gaab-braga/mds-agent-partner)**: agente em Google ADK com Gemini (Vertex AI) que responde perguntas sobre um CSV de campanhas em português, chamando funções Python para calcular e montar os gráficos. Interface em Chainlit. [Demo de 6 min](https://www.youtube.com/watch?v=8IW4VXle3JQ)
- **[case-wiz](https://github.com/gaab-braga/case-wiz)**: pipeline de DRE em camadas (raw, stg e dw) no PostgreSQL, com checagens de qualidade e uma API em FastAPI para subir o Excel e consultar o resultado.
- **[credito-pf-ml](https://github.com/gaab-braga/credito-pf-ml)**: SQL, limpeza com pandas e pipeline do scikit-learn sem vazamento, numa base sintética de crédito com problemas plantados e um gabarito para conferir a limpeza.
- **[people-analytics-turnover](https://github.com/gaab-braga/people-analytics-turnover)**: turnover na base IBM HR, com modelos validados em CV estratificada, previsão fora da dobra e dashboard em Dash.

Python (pandas, scikit-learn, XGBoost) · SQL e PostgreSQL · FastAPI · Docker · Power BI · Excel e VBA
