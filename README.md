# Gabriel Braga

Analista de dados em FP&A, em Brasília. Trabalho com Python, SQL e Power BI, e gosto de transformar planilha em pipeline que dá para testar.

### Projetos

- **[aml-transaction-monitoring](https://github.com/gaab-braga/aml-transaction-monitoring)**: detecção de lavagem de dinheiro em 5 milhões de transações (base pública IBM HI-Small, 0,18% de lavagem no teste). XGBoost com validação temporal 80/20: PR-AUC de 0,389, e das 100 transações com maior risco, 98 eram lavagem. Tem API em FastAPI, Docker e CI com testes.
- **[marketing-analytics-agent](https://github.com/gaab-braga/marketing-analytics-agent)**: agente em Google ADK com Gemini (Vertex AI) que responde perguntas sobre um CSV de campanhas em português, chamando funções Python para calcular e montar os gráficos. Interface em Chainlit. [Demo de 6 min](https://www.youtube.com/watch?v=8IW4VXle3JQ)
- **[dre-etl-pipeline](https://github.com/gaab-braga/dre-etl-pipeline)**: pipeline de DRE em camadas (raw, stg e dw) no PostgreSQL, com checagens de qualidade e uma API em FastAPI para subir o Excel e consultar o resultado.
- **[credit-risk-pipeline](https://github.com/gaab-braga/credit-risk-pipeline)**: SQL, limpeza com pandas e pipeline do scikit-learn sem vazamento, numa base sintética de crédito com problemas plantados e um gabarito para conferir a limpeza.
- **[hr-attrition-analytics](https://github.com/gaab-braga/hr-attrition-analytics)**: turnover na base IBM HR, com modelos validados em CV estratificada, previsão fora da dobra e dashboard em Dash.

Python (pandas, scikit-learn, XGBoost) · SQL e PostgreSQL · FastAPI · Docker · Power BI · Excel e VBA
